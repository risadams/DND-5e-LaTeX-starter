# Maps

Exported maps for the book, stored with Git LFS like the art.

- Use them with the template's `DndMap` environment, e.g. `\begin{DndMap}[caption=The Ruins, label=ruins]{maps/ruins}`, and place the area labels with `\DndMapArea`.
- Export without area numbers; the template draws them from the text so they always match.
- Keep the editor's files (`.dungeondraft_map`, `.psd`) in `maps/source/`, which is not committed by default.
